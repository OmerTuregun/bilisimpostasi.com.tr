Claude Code developed by Anthropic holds an important place among AI-supported software development tools. A recently revealed feature has led to discussions among developers.

Claude's commitment messages and pull request (PR) definitions automatically log URL insertion behavior, broad interest in GitHub:

- Claude in default behavior adds corresponding session link to each code change
- Although this feature is intended to provide traceability in workflow, some developers think that this creates unnecessary stack
- The discussion shared in Hacker News received 70 points and reached 72 comments
- Users request the option to check or disable this behavior
- People who open the topic indicate that such automated URLs can be problems in corporate environments

In the center of the discussion, there is a balance between developer experience and system defaults. Many users defend that such features should be configured. Especially in open source projects and multi-person teams, it is important that the commit history remains clean and tidy. Claude’s decisions will be critical for Anthropic to consider these feedbacks as they can affect code review processes.

Developers want AI tools to provide flexibility with powerful functions. This discussion shows how important AI-supported development tools should pay for user control.

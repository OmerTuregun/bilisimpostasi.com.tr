The federal government of Switzerland performs a huge change in technology infrastructure. The pilot project launched to change Microsoft software with open source solutions on corporate computers will cover 3,000 devices. This move is performed in order to reduce costs and reduce software dependence.

The basic features of the project are as follows:

- 3,000 state institution computer will be connected to open source alternatives from Microsoft software
- Linux and other open source solutions will be evaluated through pilot tests
- Government aims to save significant on software licensing costs
- The pass process will be performed gradually and the user trainings will be provided

Such initiatives are becoming increasingly common in the public sector. Many governments want to be independent of Microsoft and similar commercial software providers and find more flexible solutions. Swiss’s step can also constitute an example for other European countries.

The success of the pilot project will directly affect the reliability and availability of open source software in corporate environments. Swiss’s experiences will offer valuable data to other public institutions that think similar transitions.

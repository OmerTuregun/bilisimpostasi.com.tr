Open source video editing software OpenShot offers users professional level tools with new 4.0 version. This version aims to simplify video processing workflow for both amateur makers and professionals.

- **Direct registration feature**: It can display and audio recording directly in OpenShot without needing external software
-**: More sensitive controls have been added for coloring and color balan adjustments
- **Optimized performance**: 4.0 provides smooth editing by offering efficiency increase in processor and memory usage
- **New effects and filters**: Extended effect library provides more creative options for producers

OpenShot 4.0 makes video editing more accessible. It is especially an attractive option for users looking for alternative to cost-effective professional software. Integration of the recording feature significantly accelerates the workflow and eliminates the necessity of using separate tools.

The share made in Hacker News reveals that the technology community is interested in developing OpenShot. These types of updates in the field of open source video editing diversify the options for professional and hobby-purpose makers.

Artificial intelligence models and tools used to manage them (harnes) are not always clear for developers. Therefore, an independent developer tested 10 different models-harnes combination in the same coding task and shared its results.

The factors evaluated within the test are:

-**Model performance**: Three.js success of each combination
-**Node quality**: The accuracy and availability of the generated code
-**Speed and efficiency**: Processing time and welding use  
- **Entegration ease**: Harnesin use and configuration  u
- **Hata management**: behaviour of the system when problems are encountered  

The test results reveal that improvements vary significantly in different models and tool combinations. While some combinations complete tasks quickly, others have made more structured and accurate outputs. This comparison offers valuable data that can guide the developer teams to choose the right AI tools according to project requirements.

Broadcasting test data as open source is a practical reference source for other developers who want to evaluate artificial intelligence based software development tools.

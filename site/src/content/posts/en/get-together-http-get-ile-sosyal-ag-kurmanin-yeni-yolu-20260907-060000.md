GET Together launches a new trend in the software development community: A social network platform that works with GET HTTP method, doesn’t need post operations. This project is an interesting trial that queries the rules of traditional web architecture and implements the minimalist design philosophy.

The basic features of the project can be summarized as follows:

- **HTTP GET method’s creative use** to send data and social interaction
- Users can share and interact content without reference to the standard POST request
- The architecture of the platform reinterprets RESTful rules in the API design
- Only offers a minimalist structure that supports safe and idempotent operations

GET Together is an experimental project that tests the limits of HTTP methods in web development practice. The limited number of opinions at Hacker News (11 points, 2 comments) is valuable as a indicator of technical curiosity and innovation, although not yet seen a wide interest. Such experiments against traditional REST practice help developers understand the limits of technology.

Such minimalistic and rule-blining projects encourage creative thinking while designing web platforms. GET Together creates a disc in technology camia, although perhaps not a practical solution and gaining value as a research that offers different perspectives.

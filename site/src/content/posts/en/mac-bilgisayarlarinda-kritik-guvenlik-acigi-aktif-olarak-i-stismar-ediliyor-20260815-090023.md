Apple users are facing a serious security threat. A vulnerability discovered in the Screen Sharing feature enables attackers to bypass authentication entirely, granting them complete access to Mac computers without requiring a password.

The flaw is currently being actively exploited in real-world attacks, posing an immediate risk to users. Screen Sharing is a widely-used feature for remote support and remote work purposes, potentially affecting a large user base across both personal and corporate environments.

Apple is expected to release a security patch addressing this vulnerability as soon as possible. In the meantime, users are advised to immediately install all available system updates and consider temporarily disabling the Screen Sharing feature until a fix is available. This incident underscores the critical importance of maintaining robust cybersecurity practices to protect both enterprise networks and personal devices from emerging threats.

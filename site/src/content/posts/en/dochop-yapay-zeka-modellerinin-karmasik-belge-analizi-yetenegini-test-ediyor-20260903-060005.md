Multi-fashioned large language models (MLLM) have given successful results in visual tasks structured like graphic and document query. However, existing evaluation systems test these areas in isolation, ignore an important capability: the ability to determine how models choose, comment and merge graphics evidence using text context.

The new benchmark called DocHop aims to complete this cavity:

- **Integre structure**: It requires sense in combination with information in the document text
- **Multi-step logic**: It is mandatory to collect and process data from multiple sources to answer a single question
- **Unlimited success**: It evaluates how models fit completely new, document types not previously seen
- **Realistic scenarios**: The information reveals practical performance of models in the data set consisting of intensive documents

This benchmark will allow AI researchers to better understand the limitations of MLLMs in real world applications. As far as similar researches, text and visuals are evaluated separately, DocHop’s basic contribution is to test them in an integrated framework. As a result, this study offers new perspectives on how future-generation language models can develop for more complex information processing tasks.

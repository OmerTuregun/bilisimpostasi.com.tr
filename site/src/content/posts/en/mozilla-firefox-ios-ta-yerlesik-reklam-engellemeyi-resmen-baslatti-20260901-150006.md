Mozilla began to publish the ad blocking feature that has been tested for weeks officially in the Firefox iOS app. This new functionality aims to significantly improve users’ mobile browser experience.

The main advantages of the new ad blocking feature offered are:

- **Local solution**: No need to install a separate extension, in the case directly integrated to Firefox
- **EasyList filter**: Third-party ads and viewers are blocked without uploading pages
-**Bant width saving**: It minimizes data usage thanks to the absence of the ad and tracking codes
- **More clean web**: Mobile sites are provided to load more regularly and quickly
– **Apple’s technology is used**: System-level optimization is made using WebKit Content Blocker technology

Firefox has developed an effective solution in iOS ecosystem using Apple’s WebKit Content Blocker API strategically. This approach provides the highest performance in standard iOS app restrictions. EasyList filters are among the most widely used and reliable advertising lists on the internet.

This feature for mobile users means faster page load times and less data consumption. Firefox offers a stronger alternative to iOS market by combining user privacy and browser performance.

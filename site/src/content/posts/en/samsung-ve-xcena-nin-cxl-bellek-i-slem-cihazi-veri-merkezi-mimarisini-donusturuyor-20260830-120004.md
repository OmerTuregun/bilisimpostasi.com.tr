A new period starts in data center technology. CXL (Compute Express Link) memory processing device, which developed jointly by Samsung and Xcena, aims to solve one of the basic problems of server architecture: communication lag between memory and calculation.

* *The main features of technology can be summarized as follows:* *

- **CXL Protocol Usage**: The device uses Compute Express Link standard to provide faster data transfer between memory and processor
- **The Memory Architecture**: Near Memory Compute approach minimizes delays by transferring data processing to the same position with memory
- **Samsung and Xcena Cooperation**: Two companies offer common development efforts in industrial scale
- **Data Center Optimization**: It provides efficiency increase especially in artificial intelligence and high performance calculation applications

This approach eliminates the bottleneckes caused by data handling from **belle to processor in traditional server design**. Carrying out calculations close to the data source, increasing the process speed while reducing energy consumption. This technology offered in Hot Chips 2026 can change the way data centers perform artificial intelligence, machine learning and large-scale analytical processes.

This innovation of Xcena and Samsung looks like an important role in shaping the next generation data center infrastructure.

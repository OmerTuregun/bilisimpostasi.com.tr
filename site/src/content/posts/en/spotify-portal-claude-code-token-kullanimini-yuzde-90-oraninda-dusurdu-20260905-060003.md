Spotify engineering team managed to reduce token consumption by 90 percent while working with Claude Code model using Portal tools. This success shows how critical to optimize large language models (LLM) operating costs.

The basic success factors of the project are:

- **Portal tool integration** increased processing efficiency by eliminating unnecessary token communication
- Configuration changes made in Claude Code model are combined with prompt optimization
- Token saving significantly reduced cost in software development cycle
- Improved performance while maintaining code quality and functionality at the same level
- Spotify’s cloud infrastructure has become more efficient available

Artificial intelligence-based code writing tools are also believed to operate costs as much as software developers increase productivity. Token optimization is a vital factor for companies to adopt these technologies in scale. This experience of Spotify can lead to controlling costs in LLM-based systems.

The report on Spotify Engineering blog reveals how technology companies can integrate advanced AI tools in sustainable and cost-effective way.
